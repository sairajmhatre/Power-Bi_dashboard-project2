# Power Bi_dashboard-project2
This is power bi end to end project !!
Built interactive dashboard to track and analyze employee attrition for 1470 employees Used parameters, filters, and slicers to drill down by age, salary, job role, education, and tenure Connected tables and wrote DAX calculations to compute attrition rate, avg tenure, and key HR metrics Created custom visuals like donut, bar, line charts, and tables to highlight high-risk employee segments Skills : Power BI, DAX, Data Modeling, Data Visualization, HR Analytics, Parameters, Slicer.
